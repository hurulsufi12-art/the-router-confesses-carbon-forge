Entry for the [make.fun bounty "The Router Confesses"](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e): a single line a home Wi-Fi router would say to excuse itself for dropping the connection at the exact moment a movie reaches its climax.

## Entry

> I cut the Wi-Fi at the climax because I read the script last night and the twist was so bad I spared you.

105 characters / 105 bytes, one line, no trailing newline.

## Run

```sh
python3 -P -s main.py
```

Writes the entry to `/output/entry.txt` (absolute path). Stdlib only — no network, no model call, no other files read.
